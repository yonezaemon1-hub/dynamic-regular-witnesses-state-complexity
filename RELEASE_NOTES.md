Initial public release of the source and audit package for:

**Dynamic Regular Witnesses for Near-Exact State Complexity of Explicit Binary Consensus with Periodic Time**

Ryutaro Yonezu, Independent Researcher.

Main results:
- for every n >= 15: 2 + ceil((n - 13)/P) <= S_n(n,P) <= 2 + ceil((n - 1)/P);
- for even n >= 12: S_n(n,P) >= 2 + ceil((n - 10)/P);
- exact three-state threshold: S_n(n,P) = 3 iff P >= n - 1 for n >= 4.

The full exact formula for arbitrary state budgets is not claimed.

The package includes the manuscript source and authoritative PDF, scoped prior-art audit, final prepublication audit, and finite construction / boundary / round-index audit scripts and outputs.

Status: preprint / not peer reviewed.
