# Publication Checklist — v1.0.0

1. Create public GitHub repository `yonezaemon1-hub/dynamic-regular-witnesses-state-complexity`.
2. Upload the **contents** of this package to repository root (not the enclosing folder).
3. Verify `paper.tex`, authoritative PDF, audits, licenses, metadata, and `SHA256SUMS.txt`.
4. In Zenodo GitHub settings, **sync repositories and enable this repository before creating the GitHub release**.
5. Create GitHub tag/release `v1.0.0` from the final publication commit.
6. Confirm Zenodo automatically archives the GitHub release and issues the software DOI.
7. Backfill the software DOI into `README.md`, `CITATION.cff`, and `paper.publish.json` on `main`; keep tag `v1.0.0` fixed to the publication commit.
8. Create a separate Zenodo `Publication / Preprint` record using the authoritative PDF and `ZENODO_PREPRINT_FIELDS.md`.
9. Set publication date `2026-09-06`, version `v1.0.0`, language English, license CC BY 4.0.
10. Add the software DOI as `Is supplemented by`; add Paper 5 DOI `10.5281/zenodo.22538052` as `References` if desired.
11. Publish the preprint and record the version DOI plus all-versions DOI.
12. Backfill the paper DOI into GitHub metadata on `main` without moving the `v1.0.0` tag.
13. Update the master publication spreadsheet with Papers 5 and 7 final identifiers/status.
